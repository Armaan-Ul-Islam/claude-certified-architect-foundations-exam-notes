# Sycophancy (not in the exam guide)

The guide doesn't use this word, so this is general background.

**Sycophancy** is a model telling the user what they want to hear instead of what's true. It agrees with a wrong claim, praises weak work, or drops a correct answer when the user pushes back.

Example: a customer says "I'm in a hurry, I already verified earlier!", and the agent skips the identity check. A prompt can't fully prevent this. The guide's fix is to enforce the rule in code (see [[Deterministic-Compliance|Deterministic Compliance]], [[Domain-1-Agentic-Architecture#1.4 Implement multi-step workflows with enforcement and handoff patterns|Task 1.4]]).
