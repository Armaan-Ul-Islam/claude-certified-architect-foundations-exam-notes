# CCA-F Study Vault

An Obsidian vault of study notes for the Claude Certified Architect – Foundations (CCA-F) exam. Topic notes are linked to the 5 exam domains and the 6 exam scenarios, with a study tracker, an exam map and a page of exam tips.

## Getting started
1. Install [Obsidian](https://obsidian.md) 1.9 or newer.
2. Clone this repository.
3. In Obsidian, choose **Open folder as vault** and pick the cloned folder.
4. Open **Home** from the Bookmarks panel.

The vault's settings come with the repo: core plugins, graph colours, bookmarks and a CSS snippet. No community plugins are needed.

## Good to know
- GitHub shows `[[links]]`, the `.base` study tracker and the `.canvas` exam map as plain text. Read the vault in Obsidian.
- The "confident" ticks in the study tracker are saved in the notes, so they are shared through git.
- Using Claude Code here? It offers to install the Obsidian skills plugin, and `AGENTS.md` describes the vault's conventions.
